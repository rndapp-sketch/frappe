Danger Zone — Irreversible Actions

Every action below permanently deletes data and cannot be undone. Each requires a native confirmation dialog followed by the admin password before it runs.

🗑️ Delete Project Registrations

DANGER ZONE

Enter Project Registration names (one per line or comma-separated). Only System Manager can perform this action. Documents will be force-deleted regardless of docstatus.

🗑️ Delete DocType Records

DANGER ZONE

Enter a DocType name and one or more document names (one per line or comma-separated). Only System Manager can perform this action. Documents will be force-deleted regardless of docstatus.

🧹 Delete Comments & Activity Logs

DANGER ZONE

Fetch lists every Comment (including Workflow-transition comments — same table, different comment_type) and Activity Log tied to one document, so you can pick exactly which ones to remove. The document itself is never touched. Also works when the document no longer exists — this is the cleanup tool for comments/activity logs orphaned by a raw-SQL document delete. Only System Manager can perform this action.

🧨 Delete Project & All Associated Documents

🔒 PASSWORD PROTECTED · CASCADE — EXTREME DANGER

Enter a Project Registration document name or project number. Preview shows every linked document across all doctypes (direct links, cached project numbers, and chained references — the same map used by the PR Link Graph). Deleting removes all of it, including the Project Registration itself, and sends DELETE /api/projects/<project_no> to the external project tracking service (172.16.134.81:18080). This cannot be undone.
