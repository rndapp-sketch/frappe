What "genuine" means here

When prorndadmin impersonates someone, Frappe logs a normal "Login" event for that user at the swap — carrying prorndadmin's IP, not theirs. Those are excluded below as Impersonated. Separately, most logins in this system currently carry no resolvable client IP at all (proxy/network path issue, not impersonation) — those are excluded as Unresolved. What's left, Genuine, is this data's best evidence of who really logged in from where.

Why these have no real IP

IP resolution was broken for this system's entire history through 2026-07-27 — every login recorded a loopback/blank address, not just these ones. It started working on 2026-07-28. So this is a prediction, not a lookup: for each user below, we search their own login history (any date, not just the selected range) for a login that DID resolve to a real IP, and predict that as the most likely address for their unresolved logins too. No IP is ever guessed from another user's history. Confidence is what share of that user's own resolved logins agree on the same IP.
